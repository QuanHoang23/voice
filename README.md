# VoiceStudio — Giọng đọc tiếng Việt offline

Phần mềm đọc văn bản tiếng Việt chạy offline, có nhân bản giọng.

## Tải về

Vào mục **[Releases](../../releases/latest)** và tải file theo máy của bạn:

| Máy | File |
|---|---|
| Windows | `VoiceStudio_<phiên bản>.zip`: giải nén rồi mở `VoiceStudio.exe` |
| Mac chip Apple (M1–M4) | `VoiceStudio_<phiên bản>_mac-arm64.dmg` |
| Mac chip Intel | `VoiceStudio_<phiên bản>_mac-x64.dmg` |

Hướng dẫn chi tiết nằm sẵn trong file tải về. Đã cài rồi thì phần mềm tự cập nhật khi mở.

Kho này chỉ chứa bản phát hành, không có mã nguồn.
